# Применение ИИ в кейсе Red Wings

| Инструмент | Задача | Как проверили |
|---|---|---|
| Gemini | Первичные гипотезы по сети и вариантам роста | Пересчитали сравнение на одинаковом ресурсе и проверили, какие рейсы уже есть в программе перевозчика. |
| Perplexity | Поиск опубликованных расписаний, документов и пробелов по трём маршрутам | Сопоставили периоды, перевозчиков, единицы и ссылки. Сохранили статус проверки по каждой записи. |
| Codex | Сверка исходной таблицы, исправления, проверка итогов и подготовка материалов | Сохранили исходные выгрузки и журнал правок. Проверили, что маршрутные суммы воспроизводятся из кресел, ротаций и сценарной загрузки. |

Пример проверки: 366 125 ₽ в региональном документе указаны за парный рейс, а в федеральной шкале — за рейс в одном направлении для другой категории вместимости. Эти записи хранятся отдельно. На 100-местные рейсы Red Wings ставки из этих строк не перенесены.
